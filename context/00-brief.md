# Brief (2026-09-23)

Windows 10-style Start menu as a COSMIC panel applet, replacing the App Library
button. A-Z list, pinned tile groups (seeded from dock favourites), type-to-search,
left power/user rail. Follows COSMIC Appearance (light/dark, accent, roundness,
frost) like CCCA-40. Live tiles deferred to v2, but config carries a `source` slot.
Public repo under the jjnuthuagen alias (never real name/gmail). Approved spec:
